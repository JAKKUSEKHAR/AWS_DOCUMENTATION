## Amazon ECR (Elastic Container Registry)
**The Vault.** 
1. This is a fully managed AWS Service where you store, manage, and share your Docker container images (The packaged code ready to run).
2. It acts as a highly available and secure library for your container packages before they are deployed.
3. Integrates seamlessly with ECS and EKS to pull images quickly during deployment.
4. Scans your container images for software vulnerabilities to ensure your code is secure before running.
